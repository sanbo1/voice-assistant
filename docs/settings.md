# 設定できる項目の一覧

どこで何を変えられるか、変更がいつ反映されるかの一覧。**値の意味と決めた理由は
`docs/design.md`、測定の根拠は `docs/improvement-options.md` を参照。**

## 変更の反映について（2026-09-23 以降）

`.env` の設定は、**待ち受け中に約 1 秒ごとに確認され、数秒以内に自動で反映される**。
再起動は要らない（音声認識のモデルだけは例外）。

- 反映されると会話ログに「設定を読み直しました：〇〇 0.55 → 0.6」と出る（画面にも表示される）
- 反映は**待ち受け中だけ**。聞き取りや読み上げの途中では変わらない
- 不正な値は既定値に戻る。適用後の値がログに出るので、書き間違いに気づける
- **API キーの値はログにも画面にも出さない**（「API キーを変更しました」とだけ）
- `.env` が壊れていても本体は止まらず、直前の設定のまま動き続ける

### 「行がない」「空」「値あり」の関係

```
.env に行がない            → 既定値
VOSK_MIN_CONFIDENCE=       → 既定値（空は未設定の扱い）
VOSK_MIN_CONFIDENCE=0.52   → この値を使う
```

行を消しても既定値に戻り、これも数秒で反映される。

**`tools/setup_pi.sh` は `.env` が既にあれば上書きしない**（記入済みの API キーを消さないため）。
そのため、あとから `.env.example` に足した項目は Pi の `.env` に入っていないことがある。
足りない項目は手で追記する。

## 1. `.env` で変更できる設定

**場所**：Pi の `~/voice-assistant/.env`（雛形は `.env.example`）

| 設定値 | 概要 | 設定できる範囲 | 反映 | 画面から変更（案） |
|---|---|---|---|---|
| `WAKEWORD_CONFIRM_THRESHOLD` | **ウェイクワードの反応しやすさ。** 確認窓を通した最大スコアがこの値未満なら反応しない | 0〜1。既定 0.0、運用値 **0.55**。0 で見送りなし | 数秒 | **可**（最重要） |
| `VOSK_MIN_CONFIDENCE` | **雑音の足切り。** 聞き取りの確信度の平均がこの値未満なら AI に送らない | 0〜1。既定 **0.52**。0 で足切りなし | 数秒 | **可** |
| `FOLLOWUP_SECONDS` | 返答後、ウェイクワードなしで続けて話せる秒数 | 0 以上。既定 **3**。0 で機能を使わない | 数秒 | **可** |
| `FOLLOWUP_MAX_TURNS` | **ウェイクワードで話し始めたとき**に続けて話せる回数の上限 | 0 以上の整数。既定 **3** | 数秒 | 可（優先度低） |
| `FOLLOWUP_MAX_TURNS_KEY` | **スペースキーで話し始めたとき**に続けて話せる回数の上限（2026-09-24 追加） | 0 以上の整数。既定 **0**（1 問で待ち受けに戻る） | 数秒 | 可（優先度低） |
| `WAKEWORD_THRESHOLD` | ウェイクワードの「立ち上がり」とみなすスコア | 0〜1。既定 **0.35** | 数秒 | 不可（上級） |
| `WAKEWORD_PATIENCE_FRAMES` | 何フレーム続けて超えたら確認窓に進むか（1 フレーム 80ms） | 1 以上の整数。既定 **2** | 数秒 | 不可（上級） |
| `WAKEWORD_CONFIRM_FRAMES` | 確認窓の長さ（フレーム数） | 0 以上の整数。既定 **3**（240ms）。0 で確認窓なし | 数秒 | 不可（上級） |
| `GEMINI_MODEL` | 使う AI のモデル | モデル名。空で既定（`gemini-3.6-flash`） | 数秒（接続を作り直す） | 不可 |
| `GEMINI_THINKING_LEVEL` | AI の思考の量 | `minimal`／`low`／`medium`／`high`。空で既定 | 数秒 | 不可 |
| `GEMINI_FALLBACK_MODELS` | 上限時に使う予備モデル | カンマ区切り。`none` で予備なし。空で既定 | 数秒 | 不可 |
| `GEMINI_API_KEY` | API キー | Google AI Studio で発行した文字列 | 数秒 | **絶対に不可** |
| `AUDIO_INPUT_DEVICE` | 録音に使うマイク | 番号またはデバイス名の一部。空で既定 | **次にマイクを開き直したとき**（会話が 1 回終わってから） | 不可 |
| `AUDIO_OUTPUT_DEVICE` | 再生に使うスピーカー | 同上 | **次の再生から** | 不可 |
| `VOSK_MODEL_DIR` | 音声認識のモデル | `models/` 内のフォルダ名。既定 `vosk-model-ja-0.22`（大型）、ほかに `vosk-model-small-ja-0.22`（小型） | **再起動が必要**（約 85 秒） | 不可 |

AI の設定（`GEMINI_*`）を変えると Gemini への接続を作り直す。このとき
**「どのモデルが上限に達したか」の記憶がリセットされる**。予備モデルで動いている最中に設定を変えると
優先モデルに戻って再び 429 を受けるが、**429 は生成の枠を消費しない**ので実害はない。

## 2. 画面の設定

**場所**：Pi の `~/voice-assistant/display-settings.json`
**特徴**：`tools/deploy.sh` の対象外なので、**配置し直しても消えない**

| 設定値 | 概要 | 範囲 | 反映 |
|---|---|---|---|
| `margin_top` / `margin_bottom` / `margin_left` / `margin_right` | テレビの見切れ対策の余白 | 0〜0.2（画面比）。2026-09-23 の調整値は上下 0.025／左 0.03／右 0.025 | **`c` キーの調整モードで即座に**（Enter で保存） |
| `font_scale` | 文字の大きさの倍率 | 既定 **1.0**。1.3 で 3 割増 | **画面の再起動が必要** |

```bash
ssh raspi-voice "systemctl --user restart voice-display"   # 画面の再起動
```

画面のキー操作（スペースで聞き取り、`c` で見切れ調整、`q` で終了）は
`docs/display-spec.md` の「キー操作」を参照。

## 3. 読み替え表（誤読の修正）

**場所**：`config/readings.tsv`（1 行に「言葉＜タブ＞読み」、`#` 以降はコメント）
**反映**：**次の読み上げから即座に**（再起動不要）

**このファイルは `tools/deploy.sh` の対象。** Pi 上で直接編集すると**次回の配置で消える**。
PC 側のリポジトリで編集して配置すること。

## 5. 画面からの設定変更（段階 5・未着手）

`docs/display-spec.md` の段階 5。上表の「画面から変更（案）」列が提案。方針は 3 点。

| 方針 | 内容 |
|---|---|
| **出すのは 3〜4 項目だけ** | 反応しやすさ、雑音の足切り、続けて話せる秒数 |
| **言葉と段階に置き換える** | 「呼びかけへの反応しやすさ：5 段階」のように。変数名や数値は出さない |
| **範囲を制限する** | 極端な値にして動かなくなることを防ぐ。「初期値に戻す」も用意する |

`GEMINI_*` と `VOSK_MODEL_DIR` は画面に出さない（誤操作の影響が大きく、頻繁に変える項目でもない）。

**画面アプリに `.env` を触らせない。** API キーが入っており、書き換えるにはいったん読み込む必要があるため。
画面から変える値は別ファイル（`settings-overrides.json`）に分け、優先順位を
**画面の設定 > `.env` > コードの既定値**とする案。ただし設定が 2 か所に分かれる分かりにくさが残るので、
画面と `.env` の両方に注記が要る。
